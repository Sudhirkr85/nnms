## 🎯 PPT मुख्य विशेषताएं:
- **50-मिनट क्लासरूम फॉर्मेट:** 3 डीप थ्योरी स्लाइड्स + 15 PYQs इंटरैक्टिव 2-स्लाइड प्रारूप में।
- **Answer Hidden Mode:** प्रश्न के समय उत्तर पूरी तरह गुप्त रहता है; अगली स्लाइड पर सही उत्तर हरे रंग में चमकता है और व्याख्या सामने आती है।
- **No Meta-Prompts:** कोई टाइमर ("समय 10s") या कमेंट प्रॉम्प्ट नहीं हैं।
- **द्विभाषी शब्दार्थ:** सभी कठिन हिंदी शब्दों के साथ ब्रैकेट में अंग्रेजी रूप लिखा है।
